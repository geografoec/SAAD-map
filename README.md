# SAAD-map

Reproducible R workflow and geospatial products for the climate-based operational delineation of the South American Arid Diagonal (SAAD).

## Main output

The main output of this repository is the operational polygon of the South American Arid Diagonal (SAAD), available at:

`outputs/SAAD_polygon/SAAD_operational_polygon.gpkg`

Additional interoperable formats may also be provided in the same folder.

## Repository structure

```text
Rcode/
  01_processing/   R scripts for climate classification, aridity analysis, sensitivity analysis, and SAAD characterization
  02_figures/      R scripts used to reproduce manuscript figures

inputs/
  lagos/                 Ancillary lake/paleolake geospatial data
  Limite_Sudamerica/     South America boundary used in the workflow
  WorldClim2.1_Sudamerica/  Local WorldClim 2.1 rasters cropped to South America; not synchronized with GitHub

outputs/
  Koppen_SAAD/              Köppen–Geiger dry-climate outputs
  AI_SAAD/                  Aridity index outputs
  Koppen_SAAD_sensivity/    Spatial sensitivity analysis outputs
  SAAD_polygon/             Final operational SAAD polygon
```

## Input data note

The workflow starts from WorldClim 2.1 rasters cropped to South America. These rasters were generated by cropping the original global WorldClim 2.1 products using the South American continental boundary.

The cropped rasters are stored locally in:

`inputs/WorldClim2.1_Sudamerica/`

but are not synchronized with GitHub because of file size.
